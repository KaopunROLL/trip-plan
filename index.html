How It Works

วิธีใช้งาน

สร้างแผนทริปได้ภายใน 4 ขั้นตอนหลัก

1

กรอกข้อมูล

เลือกปลายทาง วันที่ จำนวนคน งบประมาณ และความสนใจ

2

สร้าง Smart Plan

ระบบให้คะแนนสถานที่และจัดลงตารางตามกฎที่กำหนด

3

ปรับแต่ง

เพิ่ม ลบ แก้ไขกิจกรรม หรือเลือกวิธีเดินทางใหม่

4

บันทึกและแชร์

บันทึกในอุปกรณ์ แชร์สรุป หรือพิมพ์แผนการเดินทาง

Prototype Information

เกี่ยวกับระบบ

เว็บต้นแบบสำหรับสาธิต Smart Trip Planner แบบ Rule-Based

เทคโนโลยี

  • HTML5, CSS3 และ Vanilla JavaScript
  • ทำงานจากไฟล์ index.html เพียงไฟล์เดียว
  • ไม่ใช้ Backend, Database หรือ API Key
  • LocalStorage สำหรับจัดเก็บทริป
  • SVG สำหรับแผนที่จำลอง

การแนะนำแบบ Rule-Based

  • เพิ่มคะแนนเมื่อสถานที่ตรงกับความสนใจ
  • เพิ่มคะแนนสำหรับสถานที่ที่เหมาะกับงบ
  • พิจารณาระยะเวลากิจกรรมและสไตล์ทริป
  • จัดตารางพร้อม Buffer ระหว่างกิจกรรม

ข้อจำกัด

ระบบไม่เชื่อมต่อผู้ให้บริการจอง โรงแรม ขนส่ง สภาพอากาศ หรือแผนที่แบบ Real-time

ควรตรวจสอบข้อมูลจริงก่อนเดินทาง

ความเป็นส่วนตัว
